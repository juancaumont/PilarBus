# PilarBus

# Descripción del proyecto

PilarBus es una aplicación pensada para facilitar el uso del transporte público en Pilar. Su objetivo es permitir que los usuarios consulten información sobre recorridos, paradas y horarios de los colectivos de manera sencilla y accesible.

# Objetivos

- Facilitar el acceso a la información del transporte público.
- Permitir consultar recorridos y paradas.
- Mejorar la experiencia de los usuarios.
- Ofrecer información organizada y fácil de entender.

# Organización del equipo

Para organizar el desarrollo del proyecto, el equipo utiliza Trello como herramienta de gestión de tareas mediante un tablero Kanban.

El tablero cuenta con las siguientes columnas:

- Backlog: tareas pendientes de planificación.
- To Do: tareas listas para comenzar.
- In Progress: tareas que se encuentran en desarrollo.
- Done: tareas finalizadas.

Cada tarjeta contiene subtareas, responsables y etiquetas para identificar las actividades y los roles de los integrantes.

# Uso de GitHub y Pull Requests

GitHub se utiliza para almacenar y administrar el código fuente del proyecto.

Los Pull Requests permiten proponer cambios en el código para que otro integrante pueda revisarlos antes de incorporarlos a la rama principal.

El procedimiento es:

1. Crear una rama para trabajar en una tarea.
2. Realizar los cambios y guardarlos mediante commits.
3. Crear un Pull Request.
4. Revisar y aprobar los cambios.
5. Incorporarlos a la rama principal.

# Integración y entrega continua (CI/CD)

Se propone utilizar GitHub Actions para automatizar tres etapas:

- Build: comprueba que el proyecto pueda construirse correctamente.
- Test: ejecuta pruebas automáticas para detectar errores.
- Deploy: publica la versión actualizada de la aplicación cuando se cumplen las condiciones establecidas.

# Conclusión

La combinación de Trello y GitHub permite organizar las tareas, facilitar la colaboración entre los integrantes y mantener un mejor control del desarrollo de PilarBus.
